# Klavye kısayolları

Kısayollar bir metin kutusuna (ör. arama) yazarken çalışmaz; önce listeye ya da videoya tıkla.

## Canlı TV

| Kısayol | İşlev |
|---|---|
| `Ctrl` + `↑` / `↓` | Önceki / sonraki kanal (listede görünen sırayla) |
| `PageUp` / `PageDown` | Önceki / sonraki kanal — tam ekranda ve mini pencerede |
| `0`–`9` | Listedeki sıra numarasıyla kanal seç (kısa bir beklemeden sonra ya da `Enter` ile açılır) |
| `Backspace` | Bir önceki kanala dön |
| `Enter` | Seçili kanalı oynat |
| `Ctrl` + `F` | Kanal aramasına git |
| `Esc` | Aramayı temizle |

Hızlı kanal değiştirirken kanal adı hemen görünür; yayın, durduğun kanalda yaklaşık yarım saniye sonra açılır.

## Oynatma

| Kısayol | İşlev |
|---|---|
| `F11` | Tam ekran |
| `Shift` + `F11` | İkinci ekranda oynat / ana pencereye geri al |
| `Esc` | Tam ekrandan ya da mini pencereden çık |
| `P` | Mini pencere (her zaman üstte) |
| `A` | Görüntü oranını değiştir (Otomatik → 16:9 → 4:3 → 21:9 → 16:10 → 1:1) |
| `M` | Sesi kapat / aç |
| `S` | Ekran görüntüsü al (`Resimler\Zaplio`) |
| `Boşluk` | Duraklat / devam et (canlı yayın dahil) |
| `←` / `→` | 10 saniye geri / ileri (film, dizi, arşiv) |
| `←` (canlı) | 30 saniye geri sar (arşivi olan kanallar) |
| `→` (canlı) | Canlı yayına dön |

## Fare

| Hareket | İşlev |
|---|---|
| Videoya çift tıkla | Tam ekran; mini pencerede normal pencereye dönüş |
| Mini pencereyi sürükle | Pencereyi taşı |
| Mini pencerede tekerlek | Pencereyi büyüt / küçült |
| Rehberde programa çift tıkla | Geçmiş programı arşivden, yayındakini canlı aç |
| Kanala / gruba sağ tıkla | Favori, yeniden adlandırma, sıralama ve grup gizleme menüsü |
